# Operator Workflows

Each workflow is a UX requirement only. Allowed actions create or review
metadata records; they do not implement runtime behavior.

| Workflow | Trigger | User role | Screen/panel | Required data/contracts | Allowed actions | Blocked actions | Guardian/policy/evidence requirements | Runbook links | Done criteria |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| View supervisor health | Operator opens Overview or health alert fires | owner/operator, field_it, auditor_readonly | Supervisor health | `sla.slo`, `guardian.decision`, `evidence.failure`, `incident.ops`, `console.alert` | Inspect status, filter reason codes, open runbook | Mutate services, start daemon, clear alert without evidence | Show Guardian/evidence/queue/worker/governance health refs and stale/missing data as blocked | [Health checks](../runbooks/health-checks.md) | Health state has reason code, evidence link, and next action |
| Onboard worker | New Arc mini PC prepared | owner/operator, field_it | Worker fleet, Deployment | `worker.deployment`, `worker.lifecycle`, `governance.identity`, `console.action` | Request enrollment review, link field checklist, record evidence | Install software, enable live connector, bypass identity | Guardian decision, policy bundle ref, deployment evidence, operator approval | [Worker deployment](../runbooks/worker-deployment.md), [Field IT preflight](../runbooks/field-it-preflight.md) | Worker is provisioned/enrollment-requested or blocked with reason |
| See worker heartbeat/stale worker | Heartbeat age or missed count crosses threshold | owner/operator, field_it, auditor_readonly | Worker fleet, Alerts | `worker.heartbeat`, `worker.lifecycle`, `console.alert` | Inspect heartbeat, open health evidence, start manual review | Restart service, touch endpoint, suppress without reason | Evidence refs, health reason `worker_stale`, runbook link | [Health checks](../runbooks/health-checks.md) | Stale state is acknowledged, escalated, or linked to quarantine review |
| Quarantine worker | Identity failure, evidence failure, suspicious request, or manual containment | owner/operator, security_reviewer, field_it | Worker detail | `worker.lifecycle`, `worker.heartbeat`, `incident.ops`, `console.action` | Request quarantine metadata, link incident, revoke assignment eligibility | Continue privileged work, release without review | Guardian quarantine decision, evidence refs, incident if security-related | [Worker quarantine](../runbooks/worker-quarantine.md) | Worker shows quarantined or request blocked with reason |
| Re-enroll worker | Quarantined worker requests return | owner/operator, field_it, security_reviewer | Worker detail, Deployment | `worker.lifecycle`, `worker.deployment`, `governance.update_record`, `console.action` | Request re-enrollment review, verify cache purge refs, link evidence | Automated re-enrollment, skip attestation placeholder review | Policy refs, identity recheck, capability hash, evidence, approval where required | [Worker re-enrollment](../runbooks/worker-reenrollment.md), [Worker attestation failure](../runbooks/worker-attestation-failure.md) | Worker is re-enrollment pending, active after future approval, or blocked |
| Review task queue | Task arrives or queue degrades | owner/operator, auditor_readonly | Task queue | `task.execution`, `guardian.decision`, `approval.request`, `evidence.artifact` | Inspect status, filter blocked/needs approval, open related records | Force run task, bypass Guardian, edit payload | Guardian decision and evidence state visible for each task | [Approval flow](../runbooks/approval-flow.md) | Task state and required next step are visible |
| Approve/deny task | Approval request pending | approver, security_reviewer where allowed | Approval inbox | `approval.request`, `approval.result`, `approval.token`, `token.verification`, `console.action` | Approve/deny metadata when role, scope, and evidence allow | Self-approve high-risk, approve blocked-MVP, broaden scope | Policy refs, evidence, scope hash, expiry, separation check, token metadata only | [Approval flow](../runbooks/approval-flow.md), [Approval token lifecycle](../runbooks/approval-token-lifecycle.md) | Result recorded or fail-closed reason displayed |
| Inspect Guardian decision | User opens decision from task/approval/evidence | owner/operator, approver, security_reviewer, auditor_readonly | Guardian decision detail | `guardian.decision`, `taint.ref`, `evidence.artifact` | Inspect decision, policy refs, taint, expiry, evidence | Override decision from console | Decision and evidence are immutable refs; expired/missing decision blocks action | [Prompt injection response](../runbooks/prompt-injection-response.md) | Decision context and next safe lane are clear |
| Inspect evidence artifact | User opens evidence link | permitted viewer by role | Evidence viewer | `evidence.artifact`, `evidence.failure`, `governance.audit_export` | View redacted metadata, hashes/refs, export eligibility | Show raw secrets/customer payloads, alter evidence | Redaction profile, retention class, integrity refs, access role visible | [Evidence writer failure](../runbooks/evidence-writer-failure.md) | Evidence is readable as metadata or access is denied |
| Handle evidence writer failure | Evidence writer degraded/failed | owner/operator, field_it, security_reviewer | Evidence, Alerts, Worker fleet | `evidence.failure`, `worker.heartbeat`, `incident.ops`, `console.alert` | Block privileged action, open incident, link spool refs | Continue privileged action without evidence | Pre-action failure blocks; post-action failure degrades and reconciles | [Evidence writer failure](../runbooks/evidence-writer-failure.md) | Failure is blocked/degraded with incident/evidence refs |
| Handle prompt injection/tainted input | Guardian or taint record flags input | owner/operator, security_reviewer, auditor_readonly | Guardian, Incidents | `taint.ref`, `guardian.decision`, `incident.ops`, `console.alert` | Inspect taint summary, deny or require review, link incident | Treat tainted content as operator instruction | Tainted input cannot authorize tool use, memory, sends, or remediation | [Prompt injection response](../runbooks/prompt-injection-response.md) | Taint is contained, cleared by future review, or blocked |
| Handle LIMA IT diagnostic handoff | Read-only diagnostic handoff requested | owner/operator, field_it, auditor_readonly | LIMA IT panel | `lima_it.handoff`, `incident.ops`, `evidence.artifact` | Inspect diagnostic metadata, request read-only handoff review | Execute remediation, touch production, install/update | Guardian decision, diagnostic scope, evidence refs | [LIMA IT handoff](../runbooks/lima-it-handoff.md) | Handoff is diagnostic-ready, denied, blocked, or completed mock |
| Block LIMA IT remediation | Remediation request appears | owner/operator, approver, field_it, security_reviewer | LIMA IT panel, Approval inbox | `lima_it.handoff`, `approval.result`, `guardian.decision`, `console.action` | Deny/block remediation metadata, record separation warning | Execute remediation, self-approve, production touch | Policy refs, blocked-MVP label, evidence, separation check | [LIMA IT handoff](../runbooks/lima-it-handoff.md) | Remediation remains denied/blocked with evidence |
| Connector consent/revocation review | Consent requested, revoked, or scope mismatch | owner/operator, security_reviewer, auditor_readonly | Connectors | `connector.trust`, `governance.connector_consent`, `taint.ref` | Inspect mock readiness, record revocation review, block scope | OAuth wiring, live read/write, token entry | Consent/scope/revocation refs, live access false, evidence | [Connector revocation](../runbooks/connector-revocation.md) | Connector is mock-ready, revoked, blocked, or future review required |
| Worker attestation failure review | Attestation or hash mismatch | field_it, security_reviewer, owner/operator | Deployment, Worker fleet | `worker.deployment`, `worker.lifecycle`, `governance.update_record`, `console.alert` | Quarantine/review metadata, link field checks | Automated release, privileged work, skip evidence | Attestation placeholder, policy/model hash, evidence, quarantine refs | [Worker attestation failure](../runbooks/worker-attestation-failure.md) | Worker stays quarantined/review-required until gates pass |
| Update/rollback approval | Update record needs review or rollback | field_it, owner/operator, security_reviewer, approver | Deployment/update | `governance.update_record`, `worker.deployment`, `console.action` | Approve/deny metadata, mark rollback required, pause rollout | Automatic update, install/update software, endpoint control | Signed/verified source placeholder, approval refs, known-good, evidence | [Update rollback approval](../runbooks/update-rollback-approval.md) | Update is blocked, review-required, or rollback-required with evidence |
| Access review | Review cadence or role change | security_reviewer, owner/operator, auditor_readonly | Governance | `governance.identity`, `governance.access_review` | Inspect roles, record findings, request removal/change | Self-review, approve own privileged role | MFA/access review/separation evidence refs | [Access review](../runbooks/access-review.md) | Access review is completed placeholder or changes required |
| Customer exit/delete request | Export/delete/customer exit requested | compliance_reviewer, owner/operator, auditor_readonly | Audit / Exit | `governance.audit_export`, `evidence.artifact`, `memory.access`, `worker.deployment`, `governance.connector_consent` | Review scope, redaction, conflict, connector revocation, cache purge refs | Automatic export/delete, delete evidence without conflict review | Redaction profile, non-exportable classes, preservation conflict, evidence | [Customer exit delete](../runbooks/customer-exit-delete.md) | Request is review-required, blocked, or completed mock with refs |
